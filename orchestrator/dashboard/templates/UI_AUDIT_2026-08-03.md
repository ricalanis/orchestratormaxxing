## 7. Recommendations (priority)

1. **Unify status colors**: derive `BOARD_COLUMNS`, `CYCLE_COLUMNS`, and `BACKLOG_STATUS_BORDER` dot/border colors from `STATUS_META` so `review` is one hue everywhere. Remove the separate hardcoded maps where possible.
2. **Eliminate silent fetch failures**: convert `loadCRM`, `loadGrowth`, `loadToday` sub-loaders, `deleteProduct`, `loadAgents`, and `runOmniSearch` `console.error`-only catches to either `widgetError()`/`toast('...', 'err')` or `announce()` for screen readers.
3. **Mobile omnibar**: add a mobile-visible search icon/button that opens the omnibar, or expose a bottom-sheet search on small screens. Add ARIA roles to the existing omnibar.
4. **Adopt shared empty helpers**: replace hand-rolled CRM pipeline empty state (8355), sub-deals/contacts/product-track empties, and Projects empty state with `widgetEmpty()` or `emptyState()`.
5. **Standardize breakpoints**: replace custom 639px/767px/900px media queries with Tailwind `sm`/`md`/`lg` utilities so the layout uses a single responsive vocabulary.
6. **Quantify token usage**: migrate high-value repeated color patterns (trust badges, status dots, progress bars) to `COLOR_TOKENS` so the declared design token system is actually dominant.
